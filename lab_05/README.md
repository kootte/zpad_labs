**Вимоги до системи:** Python 3.10+

**Інструкція з налаштування і запуску:**
1. Відкрийте термінал у папці `lab_05`.
2. Створіть та активуйте віртуальне середовище:
   python -m venv venv
   source venv/Scripts/activate
3. Встановіть залежності:
   pip install -r requirements.txt
4. Розмістіть ваш файл даних `vhi_data.csv` у папці `lab_05`.
5. Запустіть скрипт:
   streamlit run app.py
