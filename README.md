# Лабораторна робота №2. Наука про дані: підготовчий етап

Цей репозиторій містить виконання двох частин лабораторної роботи №2, спрямованої на опанування базових методів підготовки та аналізу даних.

## Структура проєкту

### Частина 1: Робота з даними VHI (NOAA)
**Файл: `lab2_part1.py`**
Ця частина зосереджена на автоматизації отримання та первинній обробці даних NOAA (VHI індекси для 27 регіонів України).
- **Функціонал:**
  - Автоматичне завантаження та розпакування даних.
  - Очищення "сирих" CSV-файлів (видалення зайвих символів та HTML-тегів).
  - Створення структурованого DataFrame для подальшого аналізу.
  - Реалізація функцій пошуку екстремальних значень та аналізу динаміки індексів за регіонами та роками.

### Частина 2: Аналіз споживання електроенергії
**Файл: `lab2_part2.py`**
Аналіз великого датасету "Individual Household Electric Power Consumption".
- **Функціонал:**
  - Завантаження та обробка даних із архіву UCI.
  - Проведення аналізу часу виконання запитів (за допомогою `timeit`).
  - Статистичний аналіз: нормування, стандартизація, розрахунок коефіцієнтів кореляції Пірсона та Спірмена.
  - Трансформація категоріальних ознак (One Hot Encoding).
