# Лабораторна робота №6 (C++ OpenCV)

Програма для захоплення відео з веб-камери в реальному часі з можливістю застосування різних фільтрів та ефектів за допомогою клавіатури та миші.

## Вимоги
- **ОС**: Linux (Ubuntu/Debian рекомендовано)
- **Залізо**: Наявність підключеної веб-камери.
- **ПЗ**: GCC, CMake, OpenCV.

## Інструкція запуску
1. Клонуйте репозиторій або перейдіть у папку з проєктом.
2. Встановіть залежності:
   `$ ./preinstall.sh`
3. Зберіть проєкт:
   `$ ./build.sh`
4. Запустіть програму:
   `$ ./run.sh`

## Керування
- **1** - Звичайний режим
- **2** - Інверсія кольорів
- **3** - Gaussian Blur (Розмиття)
- **4** - Фільтр Canny (Виділення меж)
- **5** - Режим малювання мишкою (затисніть ЛКМ для малювання прямокутника)
- **ESC** або **Q** - Вихід
- **Повзунок (Trackbar)** - Регулювання яскравості зображення.
