 Опис проєкту

Цей проєкт є інтерактивним веб-додатком, розробленим на мові Python з використанням бібліотеки Streamlit. Додаток призначений для аналізу та візуалізації екологічних показників стану рослинності (вегетаційних індексів):

VCI (Vegetation Condition Index) — індекс стану рослинності.

TCI (Temperature Condition Index) — температурний індекс.

VHI (Vegetation Health Index) — інтегральний індекс здоров'я рослинності.

Програма дозволяє завантажувати часові ряди показників, фільтрувати їх за часом та територіальними одиницями (областями України), сортувати дані та будувати інтерактивні графіки для аналізу динаміки й порівняння областей між собою.

 Основні можливості (Функціонал)

Інтерактивна панель керування (Sidebar):

Вибір аналізованого часового ряду (VCI, TCI, VHI) за допомогою випадаючого списку.

Вибір конкретної області України (індексовано за стандартами лабораторної роботи).

Слайдери для гнучкого налаштування інтервалу тижнів (від 1 до 52) та років (від 1981 до 2024).

Функція швидкого скидання всіх налаштувань до стандартних значень однією кнопкою.

Чекбокси для сортування даних за зростанням або спаданням обраного індексу.

Розумна обробка помилок (Валідація):

Якщо користувач одночасно активує два суперечливі чекбокси сортування («За зростанням» та «За спаданням»), програма показує попереджувальне повідомлення (Warning) та не застосовує сортування.

Графік для області: Візуалізує часовий хід (динаміку зміни) обраного індексу для вибраної області за вказаний період.

 Інструкція із запуску на Windows

Виконай ці прості кроки по черзі в командному рядку Windows, щоб запустити проєкт на своєму комп'ютері.

Крок 1: Відкриття командного рядка та перехід до проєкту

Відкрий пошук Windows (натисни клавішу Win), введи cmd та натисни Enter.

Перейди до папки з твоїм проєктом (якщо вона лежить на Робочому столі):

cd Desktop\lab5_moriarty


Крок 2: Налаштування віртуального середовища

Для запобігання конфліктам бібліотек рекомендується створити ізольоване віртуальне середовище:

Створи середовище з назвою venv:

python -m venv venv


Активуй створене віртуальне середовище:

Якщо використовуєш стандартний командний рядок (CMD):

venv\Scripts\activate


Якщо використовуєш PowerShell:

.\venv\Scripts\Activate.ps1


(Після активації з лівого боку рядка введення з'явиться зелений індикатор (venv)).

Крок 3: Встановлення залежностей

Встанови всі бібліотеки, прописані у файлі requirements.txt:

pip install -r requirements.txt


Крок 4: Запуск додатка

Запусти сервер Streamlit:

streamlit run app.py


Після виконання цієї команди Streamlit автоматично відкриє твій додаток у браузері за адресою http://localhost:8501. Якщо цього не сталося, просто скопіюй це посилання та встав його в адресний рядок браузера вручну.
