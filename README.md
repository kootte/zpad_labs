## Опис
Програма здійснює детекцію облич в реальному часі за допомогою алгоритму ResNet-10 (SSD) з використанням бібліотеки cv::dnn. 

## Інструкція з налаштування та запуску
1. Виконайте `./preinstall.sh` для завантаження моделей та бібліотек.
2. Виконайте `./build.sh` для компіляції коду.
3. Виконайте `./run.sh` для запуску програми.

## Управління
- Клавіша **F** — увімкнути режим детекції облич.
- Клавіша **N** — нормальний режим.
- Клавіша **Q** або **Esc** — вихід.
