# Лабораторна робота №3 (Python Data Science)

Програма для завантаження, очищення даних (Data Cleaning) та побудови різнопланових багатовимірних візуалізацій на базі датасету Automobile Data Set з використанням бібліотек Pandas, Matplotlib та Seaborn.

## Вимоги

* ОС: Windows / Linux / macOS
* Залізо: Будь-який сучасний ПК.
* ПЗ: Python 3.8+, встановлене віртуальне середовище, Jupyter Notebook або VS Code.

## Інструкція запуску

1. Клонуйте репозиторій або перейдіть у папку з проєктом.
2. Активуйте віртуальне середовище (рекомендовано): `$ venv\Scripts\activate`
3. Встановіть залежності: `$ pip install -r requirements.txt`
4. Відкрийте файл `lab3.py` у VS Code та запускайте клітинки через "Run Cell".
5. Або запустіть класичний Jupyter Notebook у браузері: `$ jupyter notebook`

## Побудовані візуалізації (Графіки)

* 1 - Залежність ціни автомобіля від потужності двигуна (Scatter plot)
* 2 - Розподіл цін на автомобілі рівно на 5 діапазонів (Гістограма)
* 3 - Багатовимірна візуалізація: Об'єм двигуна vs Ціна (з додаванням параметрів кузова та потужності)
* 4 - Кореляційна матриця всіх числових атрибутів (Heatmap)
* 5 - Ящик з вусами (Boxplot) для виявлення викидів у ціні за кузовом
* 6 - Кількісний розподіл автомобілів за виробниками (Barplot)
* 7 - Комбінований графік розподілу цін за типом пального (Violin Plot)
* 8 - Матриця діаграм розсіяння для швидкого аналізу кількох характеристик (Pairplot)
