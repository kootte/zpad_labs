## Опис завдання
У даній лабораторній роботі проводиться завантаження, очищення та візуалізація даних з Automobile Data Set (UCI Machine Learning Repository). Було побудовано лінійні графіки, діаграми розсіяння, гістограму з 5 діапазонами, а також багатовимірні графіки (boxplot, violinplot, heatmap, pairplot) для аналізу залежностей.

## Інструкція налаштування і запуску
1. Встановіть необхідні залежності:
   pip install -r requirements.txt
2. Відкрийте файл `lab_03.ipynb` за допомогою Jupyter Notebook або JupyterLab:
   jupyter notebook
3. Запустіть усі комірки (Run All) для завантаження даних та побудови графіків.
